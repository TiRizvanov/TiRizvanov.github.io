dbVisuals

Interactive, hardware-accelerated visualization for spatial omics in R. Queries run in DuckDB, results travel as Arrow, and the browser draws them on the GPU, so a tissue with millions of cells stays explorable on a laptop.

  • 30x+ faster than static ggplot2 at that size
  • 3-4x less memory

rDeckgl

R bindings for deck.gl. Describe a WebGL visualization as an R list, JSON or YAML, point its layers at SQL queries, and the package hydrates them through DuckDB and renders in an htmlwidget or Shiny app.

deckgl(spec, data = list(points = points))

# inside spec, a layer reads straight from SQL
data = list(type = "duckdb",
            query = "SELECT lon, lat, radius FROM points")

PRSGuard

Software can usually produce a polygenic risk score; whether that number can be interpreted for a given person is a separate question. PRSGuard checks the evidence behind each score and answers SUPPORTED, RAW_ONLY or ABSTAIN. An LLM agent gathers evidence and calls tools, but deterministic code alone decides what may be reported.

Current research

Machine learning for protein electron transfer Bravaya Lab, Boston University

I train deep-learning models that predict electronic couplings between protein residues in seconds instead of running a quantum-chemistry calculation for every pair. They are trained on 270,000+ Q-Chem calculations across 38 residue-pair types, and combined with Marcus-theory energetics in a development version of the lab's eMap software.

With the Elliott group I built a screening pipeline (sequence clustering, genome-neighborhood filtering, AlphaFold 3 modeling, electron-transfer analysis) that narrowed 18,000+ bCcP-superfamily sequences to 11 candidate MauG-like enzymes for experimental characterization. I presented it as a poster at ACS Fall 2026, where I received the Outstanding Research Award of the Division of Computers in Chemistry.
