Open-source code

Two R packages that I wrote and maintain, both released on CRAN under the MIT license. Each one bundles a JavaScript rendering layer with an R interface, hydrates data through DuckDB, and ships Shiny bindings, tests and vignettes.

rDeckgl

R bindings for deck.gl: large interactive WebGL visualizations from R through htmlwidgets, with DuckDB-backed data hydration and Shiny integration.

Source on GitHub CRAN 

library(rDeckgl)

spec <- list(
  `@@type` = "DeckGL",
  initialViewState = list(longitude = -122.4, latitude = 37.76, zoom = 12),
  layers = list(
    list(
      `@@type` = "ScatterplotLayer",
      id   = "points",
      data = list(type = "duckdb", query = "SELECT lon, lat, radius FROM points"),
      getPosition  = "@@=[lon, lat]",
      getRadius    = "@@=radius",
      getFillColor = c(255, 0, 0)
    )
  )
)

points <- data.frame(
  lon    = c(-122.40, -122.45, -122.35),
  lat    = c( 37.76,   37.78,   37.74),
  radius = c(100,      150,     200)
)

deckgl(spec, data = list(points = points), width = "100%", height = "500px")

rMosaic

R bindings for the Mosaic declarative visualization framework: linked, interactive plots with brushing and cross-filtering, queried through DuckDB or DuckDB-WASM in the browser, with selections exported back to R.

Source on GitHub CRAN 

library(rMosaic)

spec <- '{
  "data": { "df": {} },
  "plot": [{
    "mark": "dot",
    "data": { "from": "df" },
    "x": "x", "y": "y", "fill": "grp"
  }],
  "width": 600, "height": 400
}'

runMosaicApp(spec = spec, specType = "json", data = list(df = df))

Research

Bravaya Lab, Boston University September 2025 - present

Machine learning and computational chemistry - protein electron transfer

  • Deep-learning models that predict electronic couplings between protein residues in seconds instead of expensive quantum-chemistry calculations, trained on 270,000+ Q-Chem calculations across 38 residue-pair types.
  • Combined these models with Marcus-theory energy calculations in a development version of the lab's eMap software.
  • An automated screening pipeline (sequence clustering, genome-neighborhood filtering, AlphaFold 3 modeling, electron-transfer analysis) that narrowed 18,000+ bCcP-superfamily sequences to 11 candidate MauG-like enzymes for experimental characterization by the Elliott group.
